# DISHA Wiki

DISHA v6.6 is a Constitutional Evidence Operating System: a source-first, policy-gated, evidence-led intelligence workbench for high-stakes public-interest analysis.

The product is not positioned as a generic chatbot or decorative dashboard. The core promise is:

```text
If DISHA cannot prove a claim, DISHA must say so.
If DISHA can prove it, DISHA must show the chain.
```

## Current Product Spine

- Active runtime: `web/`
- API surface: `web/app/api/v1`
- Contracts and orchestration: `web/lib/unified`
- Source registry: 35 registered official/public sources
- Production spine: seven explicit capabilities for parser readiness, persistence, claim provenance, dashboard-safe data, policy-gated agents, security, and deployment readiness
- Model mode: deterministic by default, OpenAI optional and governed

## Production Honesty Rule

DISHA must not invent facts, statistics, legal references, government records, incident totals, heat maps, or source rows. Unsupported facts remain `[VERIFY REQUIRED]` until backed by repository material or a verified connector.
