# DISHA Documentation

DISHA documentation is deliberately split into three zones.

| Path | Purpose |
| --- | --- |
| `docs/public/` | Public GitHub Pages material only |
| `docs/internal/` | Maintainer documentation, API notes, product specs, release checklists, audits, and baselines |
| `docs/archive/` | Historical or superseded material |

Root `ARCHITECTURE.md` is the single source of truth for current architecture.

Do not add new documentation directly to `docs/` unless it is this routing file.
